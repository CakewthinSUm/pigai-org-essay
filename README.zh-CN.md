# pigai-org-essay

[English](README.md) | **简体中文**

一个**代理技能（agent skill）**，用来在 **批改网（pigai.org）** 上完成、修改并提交英语作文作业。批改网是个老式 PHP 应用，提交即打分，给出四项子分和逐句点评。本技能把「提交 → 看分 → 按反馈改 → 再提交」这条循环，固化成一套在这站上真能跑通的流程。

## 这站为什么难

- **编辑器禁止粘贴。** 老师开了「禁止粘贴」之后，`locator.fill()` 会弹 `您的老师启用了"禁止粘贴"选项`，还能把标签页搞死——之后所有 CDP 调用都在 `Emulation.setFocusEmulationEnabled` 上超时。唯一可靠的路是模拟真实按键（`Input.insertText` / `pressSequentially`），分块输入并逐字段核对。
- **长文本会中途被截断。** 一段一段输入，每段输完都把字段值和目标字符串比对；尾部丢了就 `ctrl+End` 补上剩余部分。
- **计分单位不是一个框。** 书信题拆成五个独立计分字段——日期、信头、正文、信尾、签名——模板里的占位提示（`Month , Year`、`Dear        ,`）只是提示，不会自动填；**"Dear" 不会替你补**。
- **字数只算正文**，所以页面上看着很满也可能不到下限。
- **重交会覆盖已显示的分数**，所以「改稿」本质是在草稿空间里做搜索，而不是分数累加。

## 流程

1. 先读任务行（作业号、标题、类型、截止时间、要求）和字数区间（常见 120–180，且会强制）。
2. 确认该题需要哪些字段；填日期 / 信头 / 正文 / 信尾 / 签名，并在 `#stu_class` 里选班级——留空老师不好批。
3. **输入而不是粘贴**，每个字段都核对精确值。
4. 提交（`#dafen`），确认弹窗；确认 URL 变成 `?c=v2&a=view&eid=…`、提交次数 +1、`.dfScore` 出分。
5. 读 词汇 / 句子 / 篇章结构 / 内容相关，加 按句点评 与 体检报告，然后按 [references/scoring-notes.md](references/scoring-notes.md) 里实测的敏感度改稿：题目词汇最直接拉动「内容相关」，长句带从句优于短句堆叠，连接词对「篇章结构」影响偏弱。
6. 再提交；到目标分就停，或者连续两次没有提升就停——并且**把最好那版重新交一次**，因为最后一次提交才算数。

## 有数据，不靠感觉

同一道题、十次提交、百分制：最好 86.5，来自「长短句平衡 + 称呼对方名字 + 出现 friend」；拆成 13 个短句掉到 83，再拆更短掉到 81。「内容相关」仅靠题目词汇就从 0.43 抬到 0.63——这是页面上最大的单根杠杆。这道题 90+ 没能达到，技能里也照实写了，不给空头承诺。完整表格见 `references/scoring-notes.md`。

## 边界

- **提交是对外、不可逆、会计分的动作。** 技能会先把草稿给你看，等你明确说交才动手。
- 它写的是这篇作业，不编造作者没有的经历、引用或出处。
- 请遵守课程的 AI 使用规定和重交次数限制——有的老师限提交次数，有的要求独立完成。用之前先看任务页和教学大纲。

## 依赖

任意能接管你**自己已登录 Chrome** 的代理（技能假定标签页已登录，从不代输账号密码）——用类似片段里的浏览器工具接口，或按 `references/browser-playbook.md` 的对照表走 CDP/Playwright。
